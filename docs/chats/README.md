# チャット記録

Cursor のフックが、このフォルダへ会話を全文で追記する。要約はしない。

- ユーザーが送信したとき: 発言の全文と、添付ファイルのパス
- アシスタントの返答が確定したとき: 画面に出た返答の全文

ツールの呼び出しと、返答前の思考は記録しない。

1会話につき1ファイル。名前は `YYYY-MM-DD_conversation-id.md`。日付は最初の発言日（Asia/Tokyo）で、会話が日付をまたいでも同じファイルに続く。

仕組みは `.cursor/hooks.json` と `.cursor/hooks/record-chat.mjs`。`2026-10-08` の手動記録は `docs/chat-2026-10-08-app-router.md` に残してある。
